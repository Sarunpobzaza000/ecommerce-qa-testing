# E-Commerce QA Testing Project

## Overview

This project focuses on testing an e-commerce website to evaluate its functionality, usability, reliability, and security-related behavior.

The main focus is the complete e-commerce checkout flow, from product discovery through cart management and checkout.

## Objectives

* Design and execute functional test cases
* Identify and document software defects
* Practice manual software testing
* Perform regression testing
* Evaluate usability and error handling
* Build automated tests for critical user flows
* Document testing results professionally

## Testing Scope

The project will cover:

* User registration and authentication
* Product search and browsing
* Shopping cart
* Checkout
* Payment-related behavior
* Order confirmation

## Project Deliverables

* Test Plan
* Test Cases
* Test Execution Results
* Bug Reports
* Screenshots and Test Evidence
* Automated Tests
* Final Test Summary
